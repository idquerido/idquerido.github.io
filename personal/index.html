Como instalar no iPhone

Safari
  1. 1
    Abra esta página no Safari

    Se estiver dentro do ChatGPT, WhatsApp ou outro aplicativo, use Abrir no Safari ou abra o link diretamente no Safari.

  2. 2
    Toque em Compartilhar

    No Safari, use o ícone de compartilhar (quadrado com seta para cima).

  3. 3
    Escolha Adicionar à Tela de Início

    Confira o nome Querido Personal e a imagem do atalho.

  4. 4
    Desative Abrir como app web

    Para o atalho deste app, deixe essa opção desligada e toque em Adicionar.

iDepois, abra o ícone criado na Tela de Início. Se já tiver um atalho com a imagem antiga, remova-o e crie outro.

Como criar o atalho no Android

Chrome
  1. 1
    Abra esta página no Chrome

    Se estiver dentro do WhatsApp, ChatGPT ou outro aplicativo, escolha Abrir no Chrome ou abra este endereço diretamente no Chrome.

  2. 2
    Toque no menu ⋮

    Procure Instalar e criar atalho no menu do Chrome.

  3. 3
    Escolha Criar atalho

    Para este aplicativo, prefira criar um atalho no Chrome, em vez de selecionar Instalar, quando houver as duas opções.

  4. 4
    Confirme em Adicionar

    Mantenha o nome Querido Personal e abra o ícone criado na Tela de Início.

iO nome do menu pode variar conforme a versão do Chrome. Em alguns aparelhos aparece Adicionar à tela inicial. Verifique que o atalho abre o Querido Personal e não fica parado nesta página.
